# エフェクト除外 for YMM4

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](#)
[![.NET](https://img.shields.io/badge/.NET-10.0-purple.svg)](#)
[![Release](https://img.shields.io/github/v/release/routersys/YMM4-EffectExclusion.svg)](https://github.com/routersys/YMM4-EffectExclusion/releases)

---

YukkuriMovieMaker4（YMM4）上で動作する、グループ制御やエフェクトアイテムの効果を特定のアイテムだけ受けないようにする映像エフェクトプラグインです。
グループ制御の範囲内にあるアイテムへ適用すると、そのアイテムだけがグループ制御のエフェクトと座標変換の影響から外れます。
エフェクトアイテムより下のレイヤーにあるアイテムへ適用すると、そのアイテムはエフェクトアイテムより後に描画されるようになり、効果を受けなくなります。
除外する相手は、対象の欄に備考欄の文字列を入力して指定します。対象の欄が空欄の場合には、そのアイテムへ影響するすべてのグループ制御とすべてのエフェクトアイテムを除外します。

## 概要

本プラグインはYMM4の映像エフェクトとして動作し、エフェクトの種類一覧では「エフェクト除外」として表示されます。カテゴリは合成です。

YMM4のグループ制御は、範囲内のアイテムへエフェクトと座標変換を一括で適用します。エフェクトアイテムは、それより下のレイヤーに描画された画面全体へエフェクトを適用します。どちらも特定のアイテムだけを対象から外す仕組みを持ちません。本プラグインは、この除外をアイテム単位で実現します。

エフェクト自体は入力の映像を変更しません。除外の処理は、YMM4の描画の仕組みへHarmonyによる実行時パッチで働きかけることで実現しています。将来のYMM4の更新によって内部の構造が変わった場合には、パッチを適用せず除外が無効になります。その場合でもエラーにはならず、エフェクトを適用していない状態と同じ表示になります。

このエフェクトはAviUtl向けのEXO出力には対応していません。

## インストール方法

1. [Releases](https://github.com/routersys/YMM4-EffectExclusion/releases/latest)ページから最新のプラグインファイル（`.ymme`）をダウンロードしてください。
2. YMM4が起動していないことを確認し、ダウンロードしたファイルを実行してインストールします。
3. YMM4を起動し、タイムライン上のアイテムに映像エフェクトを追加します。
4. 映像エフェクトの種類として「エフェクト除外」を選択してください。

## 主な機能

### 1. グループ制御の除外

グループ制御の範囲内にあるアイテムへ本エフェクトを適用すると、そのアイテムだけがグループ制御の影響から外れます。グループ制御が与える映像エフェクトに加えて、座標、拡大率、回転などの座標変換もあわせて除外します。

除外は、アイテムのエフェクトの構成をフレームごとに確定する直前に、対象のグループ制御に由来するエフェクトを取り除くことで行います。除外はアイテム単位で働くため、同じグループ制御の範囲内にある他のアイテムには影響しません。除外はそのフレームから反映され、遅延はありません。

### 2. エフェクトアイテムの除外

エフェクトアイテムは、それより下のレイヤーに描画された画面全体へ効果を適用します。合成した後の画面から特定のアイテムの画素だけを取り除くことはできないため、本エフェクトは描画の順番を変えることで除外を実現します。

対象のエフェクトアイテムより下のレイヤーにあるアイテムへ本エフェクトを適用すると、そのアイテムはエフェクトアイテムの直後に描画されるようになり、効果を受けなくなります。描画の順番が変わるため、除外したアイテムはそのエフェクトアイテムの結果よりも手前に表示されます。また、対象のエフェクトアイテムより下にある他のエフェクトアイテムの効果も同時に受けなくなります。複数のアイテムを除外した場合には、アイテム同士の相対的な描画の順番を維持します。

### 3. 備考欄による対象の指定

対象の欄には、除外したいグループ制御やエフェクトアイテムの備考欄の文字列を1行に1件ずつ入力します。備考欄の文字列と入力した行の文字列は、前後の空白を取り除いた上で完全に一致した場合にだけ対象になります。空白だけの行は無視します。

対象の欄が空欄の場合には、そのアイテムへ影響するすべてのグループ制御とすべてのエフェクトアイテムを除外します。

### 4. Harmonyの衝突回避

除外の処理にはHarmonyによる実行時パッチを使用します。YMM4はプラグインフォルダー内のすべてのDLLを同じ読み込みコンテキストへ読み込むため、複数のプラグインが異なるバージョンの`0Harmony.dll`を同梱すると衝突します。

本プラグインは、Harmonyをサブモジュールからソースビルドし、`EffectExclusion.0Harmony.dll`という専用のアセンブリ名で同梱します。他のプラグインが同梱するHarmonyとは別のアセンブリとして読み込まれるため、バージョンの衝突は起こりません。

## 制限事項

- AviUtl向けのEXO出力には対応していません。
- 画像を合成が有効なグループ制御は、範囲内のアイテムをまとめて描画した後の画像へ効果を適用するため、除外できません。
- 立ち絵アイテムの表情による効果は除外の対象になりません。
- エフェクトアイテムの除外では描画の順番が変わるため、除外したアイテムは対象のエフェクトアイテムの結果よりも手前に表示されます。

---

## 注意事項

- 内部実装への依存: 除外の処理はYMM4の内部の描画の仕組みに依存しています。YMM4の更新によって内部の構造が変わった場合には、パッチを適用せず除外が無効になります。その場合でもエラーにはならず、エフェクトを適用していない状態と同じ表示になります。
- 対象の一致判定: 備考欄の文字列と対象の欄の各行は、前後の空白を取り除いた上で完全に一致した場合にだけ対象になります。部分一致では対象になりません。
- 同梱ライブラリ: Harmonyを`EffectExclusion.0Harmony.dll`という専用のアセンブリ名で同梱しています。`EffectExclusion.dll`と同じフォルダーへ配置してください。
- 更新通知: エフェクトを最初に生成したときに、YMM4の実行中に一度だけ新しい正式版を確認します。更新情報を取得できない場合は通知せず、そのまま動作します。プレリリースは通知の対象に含めません。
- 本プラグインを使用する前に、YMM4のプロジェクトファイルのバックアップを作成することを推奨します。
